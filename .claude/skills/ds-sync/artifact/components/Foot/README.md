# Foot

The site footer: copyright on the left, Email, LinkedIn and Résumé links on the right, over an in-flow `line` divider.

**When to use.** Every page, once, via `<dc-import name="Foot">`. It is a site component (`Foot.dc.html`), not part of the bundle.

**Divider.** The line is drawn at content width (32px gutters) because the footer usually follows a section on its own background. Where it follows a different background, that page extends the line in its own style (LAY-05b, see `work.html`).

**This card** is a static rendition of the rendered footer.
