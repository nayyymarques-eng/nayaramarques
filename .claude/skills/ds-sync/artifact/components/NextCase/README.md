# NextCase

Closes a case study: the next case's title with its tag, linking to it.

**When to use.** Last block of every case page, after the dark call to action (LAY-07). Titles must match the case titles in Build rules (CNT-08).

**Props.** `title`, `href`, `tag` (the client or context), `label` (default "Next case study"). Extra attributes pass through to its `<section>`.

**On the site.** `<x-import component-from-global-scope="NayaraSilvaDesignSystem_5f30f3.NextCase" title="Capacity matching for private truck fleets" href="fleet-optimizer.html" tag="Loadsmart">`
